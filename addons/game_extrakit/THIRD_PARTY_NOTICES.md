# Dependencias externas

GameExtrakit consume las APIs públicas de:

- [Godot Play Game Services](https://github.com/godot-sdk-integrations/godot-play-game-services)
  de godot-sdk-integrations, commit `e38b618578572b558691c4f476f70f5e142226ce`.
- [GodotApplePlugins](https://github.com/migueldeicaza/GodotApplePlugins)
  de Miguel de Icaza y colaboradores, commit `a2ae65df061c80d66420e23572300cc9ffcedb7c`;
  componentes Game Center y SwiftGodotRuntime.

Este paquete no redistribuye su código fuente, binarios, SDKs ni documentación.
Al instalar/distribuir sus paquetes conserva los avisos y condiciones de licencia
incluidos en cada referencia oficial. Google Play Games, Game Center y Godot son
productos de sus respectivos titulares. No se incluye el SDK independiente de Sidekick.
